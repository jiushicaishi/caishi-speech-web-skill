# 网页讲解明暗·节奏·主题规则 references/web-rhythm
> 本技能"不丑"的秘诀：明暗节奏 + 每页信息量 + 主题纪律。

## 一、明暗节奏规则

- 每页 dark:true/false 决定深底(夜空档案风)或浅底(纸张档案风)。
- **同一章内相邻页避免同底同模板**：深—浅交替最稳；整章不宜连续 ≥3 深 或 ≥3 浅。
- 章节页（divider）固定深底；纯文字页、照片页可浅可深，看前后页调剂。
- 深底页信息密度低些（留白多、字距大）；浅底页承载要点卡/数据。
- 实拍照片页的底色考虑照片主体：深色太空照可配深底白卡，亮色现场照配浅底。

## 二、信息量与分钟节奏

| 页类型 | 要点条数 | 预估分钟 | 备注 |
|---|---|---|---|
| divider/cover/end | — | 0.8–1.5 | 转场不恋战 |
| cols 图文 | 3–4 | 1.6–1.8 | 图是记忆点 |
| plain 卡片 | 4（2×2） | 1.4–1.8 | 每条一行半内 |
| nums 数字页 | 4 卡 | 1.6 | 数字要念准 |
| full 大图 | 0–1 短句 | 1.4–1.6 | 图说话 |

- 全篇合计分钟 = Σ minutes；封面 meta 口径要跟上（改页后核对，31 页 ≈ 49 分钟）。
- 每条要点一句话（≤40 字），数据放句首；金句/提问放 talk 里由讲解员掌控。

## 三、内容排版纪律（anti-"AI 味"）

1. 标题有信息量，不用"探索/启航/梦想"空词堆砌；能带数字/地名/时间更佳。
2. 同页色不超过 3 类（底/字/金 强调各司其职）。
3. 对齐克制：左对齐为主，大标题勿全居中（封面/章节除外）。
4. 每页一个"记忆点"：一张好图、一组数字或一句金句，不平均用力。
5. 字距/行高宁大勿小；深底字用亮白非纯灰。

**纪律：**
- 新增组件/页面样式只许 `var(--…)`，禁止写死 hex（三主题换肤会破）。
- 深底页 h1 金属渐变引用 --metal-a..d；dark 背景引用 aurora/base 变量。
- 字体变量 --serif(衬线标题)/--sans(正文)/--mono(编号)跨主题不变。
- 打印/观众模式下星点与 kframe 已按 media print 处理，主题仅影响配色，无布局差异。
